# Phase 3: Customer Storefront (Angular 20) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a responsive Angular 20 customer-facing web application for browsing products, managing carts, and completing purchases.

**Architecture:** Component-based Angular frontend consuming REST APIs from Phase 2 backend. Feature-module organization with lazy loading. State management via RxJS observables. Bootstrap 5 for styling.

**Tech Stack:**
- **Runtime:** Node.js 22+, npm 11+
- **Framework:** Angular 20
- **Language:** TypeScript 5.6+
- **HTTP Client:** Angular HttpClient with interceptors
- **State:** RxJS observables (BehaviorSubject for shared state)
- **Styling:** Bootstrap 5, SCSS
- **Build:** Webpack (Angular CLI default)
- **Testing:** Jasmine + Karma (unit), Cypress (e2e)
- **Package Manager:** npm

---

## Global Constraints

**Environments:**
- Development: `ng serve` on localhost:4200
- Production: `ng build --configuration production` (AOT enabled)
- API Base: Environment-based (`environment.ts` dev, `environment.prod.ts` production)

**Version Floors:**
- Node.js 22.0.0+
- npm 11.0.0+
- Angular 20.0.0+
- TypeScript 5.6.0+
- Bootstrap 5.3.0+

**Architecture Decisions:**
- Feature modules with lazy loading for scalability
- Smart (container) components handle state/API calls, dumb (presentational) components render UI
- All HTTP calls in services (not components directly)
- Environment-based API URLs (no hardcoded endpoints)
- RxJS unsubscribe pattern (OnDestroy hook) to prevent memory leaks
- Error handling interceptor for 401/403/500 responses
- Loading indicators for all async operations

**Naming Conventions:**
- Components: `PascalCase.component.ts` (e.g., `ProductList.component.ts`)
- Services: `PascalCase.service.ts` (e.g., `ProductService.service.ts`)
- Modules: `PascalCase.module.ts` (e.g., `CatalogModule.ts`)
- Models/Interfaces: `PascalCase.ts` in `models/` folder (e.g., `Product.ts`)
- Feature folders: kebab-case (e.g., `product-catalog/`, `shopping-cart/`)

**API Contract:**
- Base URL: Phase 2 REST API (e.g., `/api/v1/products`, `/api/v1/categories`)
- Response format: `ResponseData<T>` wrapper with `statusCode`, `message`, `data`, `errors`
- Authentication: JWT bearer token in `Authorization: Bearer {token}` header
- Multi-tenancy: Tenant slug in URL path or header

```typescript
import { Injectable } from '@angular/core';
import { HttpClient, HttpParams } from '@angular/common/http';
import { Observable } from 'rxjs';
import { environment } from '@env/environment';
import { ApiResponse, PagedResult } from '../models/api-response.model';

@Injectable({ providedIn: 'root' })
export class ApiService {
  private apiUrl = environment.apiBaseUrl;

  constructor(private http: HttpClient) {}

  get<T>(endpoint: string, params?: HttpParams): Observable<ApiResponse<T>> {
    return this.http.get<ApiResponse<T>>(`${this.apiUrl}/${endpoint}`, { params });
  }

  post<T>(endpoint: string, body: any): Observable<ApiResponse<T>> {
    return this.http.post<ApiResponse<T>>(`${this.apiUrl}/${endpoint}`, body);
  }

  put<T>(endpoint: string, body: any): Observable<ApiResponse<T>> {
    return this.http.put<ApiResponse<T>>(`${this.apiUrl}/${endpoint}`, body);
  }

  delete<T>(endpoint: string): Observable<ApiResponse<T>> {
    return this.http.delete<ApiResponse<T>>(`${this.apiUrl}/${endpoint}`);
  }
}
```

**Step 1: Create auth interceptor**

`src/app/core/interceptors/auth.interceptor.ts`:
```typescript
import { Injectable } from '@angular/core';
import { HttpInterceptor, HttpRequest, HttpHandler, HttpEvent } from '@angular/common/http';
import { Observable } from 'rxjs';

@Injectable()
export class AuthInterceptor implements HttpInterceptor {
  constructor(private authService: AuthService) {}

  intercept(req: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> {
    const token = this.authService.getToken();
    if (token) {
      req = req.clone({
        setHeaders: {
          Authorization: `Bearer ${token}`,
        },
      });
    }
    return next.handle(req);
  }
}
```

```typescript
import { Injectable } from '@angular/core';
import { BehaviorSubject, Observable } from 'rxjs';
import { map } from 'rxjs/operators';
import { ApiService } from '@app/core/services/api.service';
import { LoginRequest, LoginResponse, RegisterRequest, CurrentUser } from '../models/auth.model';

@Injectable({ providedIn: 'root' })
export class AuthService {
  private currentUser$ = new BehaviorSubject<CurrentUser | null>(null);
  private isAuthenticated$ = new BehaviorSubject<boolean>(false);

  constructor(private apiService: ApiService) {
    this.loadCurrentUser();
  }

  login(request: LoginRequest): Observable<LoginResponse> {
    return this.apiService.post<LoginResponse>('auth/login', request).pipe(
      map(response => {
        this.setToken(response.data.accessToken);
        this.isAuthenticated$.next(true);
        return response.data;
      })
    );
  }

  register(request: RegisterRequest): Observable<LoginResponse> {
    return this.apiService.post<LoginResponse>('auth/register', request).pipe(
      map(response => {
        this.setToken(response.data.accessToken);
        this.isAuthenticated$.next(true);
        return response.data;
      })
    );
  }

  logout(): void {
    this.clearToken();
    this.isAuthenticated$.next(false);
    this.currentUser$.next(null);
  }

  getToken(): string | null {
    return localStorage.getItem('access_token');
  }

  setToken(token: string): void {
    localStorage.setItem('access_token', token);
  }

  clearToken(): void {
    localStorage.removeItem('access_token');
  }

  isAuthenticated(): Observable<boolean> {
    return this.isAuthenticated$.asObservable();
  }

  getCurrentUser(): Observable<CurrentUser | null> {
    return this.currentUser$.asObservable();
  }

  private loadCurrentUser(): void {
    const token = this.getToken();
    if (token) {
      this.isAuthenticated$.next(true);
```

`src/app/features/auth/components/login.component.ts`:
```typescript
import { Component, OnInit, OnDestroy } from '@angular/core';
import { FormBuilder, FormGroup, Validators } from '@angular/forms';
import { Router } from '@angular/router';
import { Subject } from 'rxjs';
import { takeUntil } from 'rxjs/operators';
import { AuthService } from '../services/auth.service';

@Component({
  selector: 'app-login',
  templateUrl: './login.component.html',
  styleUrls: ['./login.component.scss'],
})
export class LoginComponent implements OnInit, OnDestroy {
  loginForm!: FormGroup;
  isLoading = false;
  errorMessage: string | null = null;
  private destroy$ = new Subject<void>();

  constructor(
    private fb: FormBuilder,
    private authService: AuthService,
    private router: Router
  ) {}

  ngOnInit(): void {
    this.initializeForm();
  }

  initializeForm(): void {
    this.loginForm = this.fb.group({
      email: ['', [Validators.required, Validators.email]],
      password: ['', [Validators.required, Validators.minLength(6)]],
    });
  }

  onSubmit(): void {
    if (this.loginForm.invalid) return;

    this.isLoading = true;
    this.errorMessage = null;

    this.authService
      .login(this.loginForm.value)
      .pipe(takeUntil(this.destroy$))
      .subscribe({
        next: () => {
          this.router.navigate(['/products']);
        },
        error: (err) => {
          this.errorMessage = err.error?.message || 'Login failed';
          this.isLoading = false;
        },
      });
  }

  ngOnDestroy(): void {
    this.destroy$.next();
    this.destroy$.complete();
  }
}
```
